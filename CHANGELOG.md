1.5 (LIGHT):

This is the "LIGHT" release: a major cleanup and optimization pass with no new content added. The goal was to make the mod smaller, faster, and more stable before we continue adding features and fixing bugs.

Mod file size reduced by roughly 4-5x compared to 1.4.3.5, by removing unused/duplicate texture files and dead code left over from earlier development.
Sculk Sensors (Soul and Radioactive) now only trigger their effect on a player within 3 blocks, instead of a much larger and inconsistent range.
Sculk Mob Spawners now spawn as soon as a player gets within 10 blocks, instead of 18.
Fixed a bug where Sculk Mob Spawners generated naturally in structures (worldgen) could fail to ever activate, since their tick loop only started when placed by hand. They now also self-start using the game's natural random-tick system, so naturally generated spawners work reliably.
Sculk Chests generated naturally in structures had the same "never starts" bug; fixed the same way, and their open/close animation is also more responsive now.
Removed the unfinished "Arda's Sculks Book" guide item and its menus, since it was left incomplete and unused.
Heavily optimized several procedures (Advanced Furnace, Deepslate Dispenser, sensors, spawners, bosses) that were doing far more work per tick than necessary; server performance impact from these should now be significantly lower.
Removed several dead/unused files left over from earlier MCreator-based development that had no effect on gameplay.
General code quality cleanup throughout.

We'll keep improving from here: more bugfixes and quality-of-life fixes are planned for upcoming updates.
